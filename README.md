# Automated-Network-Request-Management


Project Overview

This project automates the network request process using ServiceNow. Users can submit requests through the Service Catalog, and the system automatically creates a record, sends a confirmation email, and initiates the approval process using Flow Designer.

About the Project

The Automated Network Request Management project is built using ServiceNow to simplify and automate network service requests. It uses Service Catalog, Flow Designer, email notifications, and approval workflows to manage requests efficiently.
